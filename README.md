# Multi agent dev assistance

This is multi agent dev assistance to show how multiple agents can communicate each other to perform cross domain task.

There is a central agent which takes the request in natural language and redirect to appropriate agent to perform the task.

The agentic workflow has build with the help of langchain and LLM running in ollama

## Package used-
langchain </br>
ollama
